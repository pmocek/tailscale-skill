## Threat Model (STRIDE)

| Threat Type | Identifier | Scenario | Planned Mitigation |
|-------------|------------|----------|--------------------|
| **Spoofing** | T-02-01 | Malformed or spoofed external URLs pointing to non-Tailscale domains or phishing pages. | All external documentation links in `SKILL.md` are locked to official, secure `https://tailscale.com/*` or `https://login.tailscale.com/*` HTTPS destinations per D-13. |
| **Tampering** | T-02-02 | Accidental alteration or deletion of core operational concepts (Grants, CGNAT IPs, MagicDNS, gotchas) during link refactoring. | Edits are strictly targeted to navigation sections (`## Quick start`, `## Find your task`, `## CLI quick reference`, `## Getting help`). The core mental models (`## Core concepts`, `## Authoring defaults`, `## Common gotchas`) remain unmodified. |
| **Repudiation** | T-02-03 | Inconsistent link syntax causing silent link resolution failures in downstream agent harnesses (Claude Code, Antigravity, OpenCode). | Normalize 100% of reference links to standard clickable relative markdown links and validate using automated AST/regex file existence checks. |
| **Information Disclosure** | T-02-04 | Inadvertent inclusion of real authentication keys, admin tokens, or production URLs in reference examples. | All documentation snippets preserve sanitized placeholder tokens (`tskey-auth-xxxxx`, `$TOKEN`) and generic 100.x CGNAT addresses. |
| **Denial of Service** | T-02-05 | Context window exhaustion (>2,000 tokens) in `SKILL.md` or cyclic link loops causing agent retrieval runaway. | `SKILL.md` maintains a high-density, low-token routing index (~750 tokens, well below standard limits). All inter-reference links are horizontal DAG links without circular loops. `token_estimate.py` verifies budget compliance. |
| **Elevation of Privilege** | T-02-06 | Misleading routing directing users to execute elevated or destructive CLI commands without notice. | `SKILL.md` references `cli.md` and `cli-diagnostics.md` which embed explicit agent operating rules (verify before guessing, confirm destructive actions, privilege handling). |
