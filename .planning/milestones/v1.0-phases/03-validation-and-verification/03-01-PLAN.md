<task id="03-01-01" type="tracer">
  <name>Implement markdown relative link and anchor integrity checker (scripts/check_links.py)</name>
  <files>scripts/check_links.py</files>
  <action>
    Create `scripts/check_links.py` using Python 3 standard library modules (`argparse`, `pathlib`, `re`, `sys`) to validate all internal markdown links and heading anchors across the skill per D-07, D-08, and ROUT-04:
    1. Strip fenced code blocks (````.*?````) using DOTALL regex substitution before parsing links and headers, preventing false positives on code examples or snippets.
    2. Implement GitHub Flavored Markdown (GFM) heading slugification:
       - Lowercase header text.
       - Strip HTML tags (`<[^>]+>`).
       - Remove punctuation characters, retaining alphanumeric, hyphens, and whitespace (`[^\w\s-]`).
       - Replace whitespace sequences and underscores with hyphens (`[\s_]+` -> `-`).
       - Handle duplicate heading slugs in the same file by appending incrementing suffixes (`-1`, `-2`, etc.).
       - Support explicit HTML anchors (`<a id="...">`, `<span id="...">`, `<a name="...">`).
    3. Traverse `SKILL.md` and all files in `references/*.md` for the specified skill directory.
    4. For each relative markdown link:
       - Ignore external URLs (`http://`, `https://`, `mailto:`, `ftp:`).
       - Partition target into file path and optional `#anchor` fragment.
       - Resolve relative target path using `pathlib.Path.resolve()`, validating safe path containment to prevent path traversal outside expected boundaries per threat T-03-01.
       - Assert that the target file exists on disk.
       - If an anchor is present, verify that the anchor slug exists in the target file's cached anchor set.
    5. Output summary statistics (files checked, total relative links checked, broken link count) and return exit code 0 when all links pass, or exit code 1 if any broken file or anchor link is detected.
  </action>
  <verify>
    <automated>python3 scripts/check_links.py skills/tailscale</automated>
    <fails_when>non-zero exit code or any broken relative links or anchors reported</fails_when>
  </verify>
  <done>
    `scripts/check_links.py` executes without dependencies beyond Python standard library, scanning all 21 markdown files in `skills/tailscale` and reporting 0 broken links and 0 broken anchors with exit code 0.
  </done>
</task>
